# Claude Design — как организовать рекламные креативы

## Вступление

Цель — производить рекламные креативы (Instagram Stories, Feed, баннеры маркетплейсов, билборды, A4 print) под четыре бренда одного завода: ФИЛЛС, ЛыткаринЪ пиво, BrewPrompt, ЛыткаринЪ лимонады. Каждый бренд имеет собственный DNA, целевую аудиторию и ценовой сегмент — смешивать их в одном пространстве проблематично. Claude Design используется как хранилище brand-контекста и генератор вариаций: загружаешь бриф + ассеты один раз, дальше итерируешь на основе токенов каждого бренда.

---

## Принцип: 4 проекта или 1 общий

**Один общий проект** — кажется удобным на старте, но на практике:
- Контекст разных брендов конкурирует: запрашиваешь Stories для BrewPrompt, модель тянет цвета ФИЛЛС.
- Трудно изолировать итерации: правки для одного SKU ломают референсы другого.
- Сложно делегировать: если к проекту подключается дизайнер или агентство, они видят всё.

**4 отдельных проекта** — рекомендованная схема:
- Каждый проект = один brand DNA, свои шрифты, палитры, тон.
- Шаблоны форматов (Stories 1080×1920 и т.д.) дублируются в каждый — это нормально.
- Общий ассет один: `logo_lytkarin.png` (логотип завода). Хранить в отдельной папке **ASSETS-PUBLIC** и загружать в каждый проект, где логотип нужен.

Имена проектов: `FILLS-creatives`, `LYTKARIN-BEER-creatives`, `BREWPROMPT-creatives`, `LYTKARIN-LEMONADY-creatives`.

## Что грузить в каждый проект

### ФИЛЛС (готово, много материала)

Из репозитория: всё в `design/fills/`, `assets/`, `research/fills/`, `production/fills/`.

**Бриф** — создать отдельный файл `fills-brief.md` (1 экран), источник: `research/fills/strategiya.md`. Загрузить первым — это главный ориентир для модели.

**Развёртки банок** (`design/fills/razvertki/`) — 6 PNG-файлов, по одному на SKU. Используются как референс формы, зон печати и расположения логотипа.

**AI-файлы** (`design/fills/editable-ai/`) — 6 редактируемых Illustrator-файлов. Нужны, если надо вытащить вектор логотипа, иконок или фреймов. Грузить в проект не обязательно — достаточно держать локально и подтягивать по запросу.

**Chrome bevel gradient — справочник цветов** (`design/fills/preview/etiketka-preview.html`) — источник точных hex-значений градиентов и bevel-эффекта логотипа. Снять скриншот или вытащить токены в таблицу перед загрузкой в Claude Design.

**Палитра 6 SKU:**
| SKU | Цвет 1 | Цвет 2 |
|-----|--------|--------|
| Клубника+Базилик (флагман) | Коралл `#FF6B6B` | Мята `#34D399` |
| Виноград+Крем-сода | Фиолет `#A855F7` | Беж `#F5E6D3` |
| Клюква+Апельсин+Розмарин | Бордо `#8B1A1A` | Терракот `#C2714F` |
| Клубника+Арбуз | Коралл `#FF6B6B` | Ярко-розовый `#FF1493` |
| Огурец+Лимон+Лайм | Бледно-зелёный `#B8E4B8` | Прозрачный/белый |
| Гранат+Клубника+Грейпфрут+Чили | Глубокий красный `#8B0000` | Розовый `#FFB6C1` |

**Типографика** (из `index.html`): Inter (основной), Space Grotesk (акценты, названия вкусов). Обе доступны через Google Fonts — указать в брифе ссылки.

**Фото банок** (`assets/fills_*.png`) — рендеры банок на тёмном фоне. Грузить все 6 — используются как product-hero для карточек маркетплейса и Stories.

**Фоны** (`assets/фон_*.png`) — большие фоновые изображения для Stories и билбордов.

**Иконки для лендинга** (`.webp` в корне: `klubnika-bazilik.webp`, `vinograd-krem-soda.webp` и т.д.) — облегчённые версии для быстрых набросков.

**Штрихкоды** (`assets/barcodes/`) — по SKU, нужны для карточек маркетплейса и A4-листовок. Грузить как отдельные PNG.

**Состав + КБЖУ** (`production/fills/tehnolog/состав.md`) — обязателен для food-info-блоков на карточках маркетплейса.

**Конкуренты** (`research/fills/konkurenty.md`) — не грузить в сессии генерации; держать под рукой для сессий "чем отличаемся".

### ЛыткаринЪ пиво (в работе)

Материала меньше, работа ещё идёт.

**Логотип** (`logo_lytkarin.png`) — основа всего. Загрузить первым.

**Превью визиток** (`design/lytkarin-beer/vizitki/vizitki.html`) — снять скриншот или открыть в браузере: это рабочий источник цветовых токенов.

Цвета из `vizitki.html`:
- Тёмно-зелёный `#1a4d2e` — основной фон
- Золото `#d4a574` — акцент, текст на тёмном
- Медь `#b87333` — вторичный акцент

**Типографика**: PT Serif (антиква, заголовки) + Inter (гротеск, тело текста). Те же шрифты что в брифе lytkarin-beer.md.

**Промпты этикеток** (`prompts/lytkarin-beer/etiketki.md`) — использовать как style-reference: описания стилей Светлое / Нефильтр. / Пшеничное / Тёмное / Безалк.

**Промпты визиток** (`prompts/lytkarin-beer/vizitki.md`) — референс тона и подачи.

**Стратегия** (`research/lytkarin-beer/strategiya.md`) — создать выдержку для брифа (1 экран).

**Что нужно добавить позже:**
- Фото / рендеры банок (когда будут готовы)
- Mood-board: физические референсы солидного регионального пива (не китч, антиква + тёмные тона)
- Полная типографическая спека (финальные шрифты)

### BrewPrompt (с нуля)

Материала в репо нет. Всё создавать в процессе работы над проектом.

**Бриф-стартер** (создать руками и загрузить):

```
BrewPrompt — премиальное крафтовое пиво от завода ЛыткаринЪ.
Сегмент: 200-300 ₽, ниша между массом (Балтика, ЛыткаринЪ) и дорогим крафтом (Zagovor 450+).
Позиционирование: "пиво уровня Bakunin/Stamm, но доступнее".
Дизайн: ФИЛЛС-стиль адаптированный под пивные коды — градиент + grain-текстура + spot UV.
Стили: IPA, Stout, Pale Ale (первая волна).
```

**Mood-board** (собрать ссылки или скриншоты):
- Bakunin Drinks (Россия) — цветовая смелость, grain
- Stamm Beer (Россия) — минимализм, типографика
- AF Brew (Россия) — иллюстративность
- ФИЛЛС собственные — как родительский язык

**Палитра по стилям:**
| Стиль | Цвет 1 | Цвет 2 |
|-------|--------|--------|
| IPA | Жёлто-оранжевый `#FFB800` | Янтарь `#E8730A` |
| Stout | Чёрный `#1A1A1A` | Кофе `#4A2C1A` |
| Pale Ale | Бледно-золотой `#F5D78E` | Медь `#C68B47` |
| Лимитки/сезонные | По вкусу выпуска | TBD |

**Типографика**: Inter + Space Grotesk (наследование от ФИЛЛС) — сохраняет визуальную связь внутри портфеля завода.

**Логотип BrewPrompt** — нужно сгенерировать. Задача для отдельной сессии в Claude Design: wordmark на базе Inter Bold + геометрический знак (кружка / колба / prompt-курсор). До готовности логотипа — использовать рабочее обозначение "BrewPrompt" в Inter 700.

### ЛыткаринЪ лимонады (опция, концепт)

Запускается только при подтверждении. Если да — отдельный четвёртый проект.

**Позиционирование**: массовые газированные лимонады в ретро-стеклянной бутылке 0.5 л, 45-65 ₽. Тархун, Дюшес, Барбарис, Крем-сода.

**Стиль**: ретро-патриотический. Референс — Калиновъ Лимонадъ, Натахтари советская серия, советские ГОСТ-этикетки 1970-80х.

**Палитра**:
- Бежевый / тёплый белый `#F5F0E8` — фон
- Золото / охра `#C8860A` — основной акцент, вензеля
- Бордо `#6B1A1A` — для Барбариса, Тархуна
- Зелёный `#2D5A27` — Тархун
- Тёплый жёлтый `#E8C547` — Дюшес

**Типографика**: антиква с засечками — Playfair Display, Cormorant Garamond или аналог. Кириллические вензели — рассмотреть Бесплатный шрифт «Введенский» или аналог с ятями/ъ.

**Что грузить**: только `logo_lytkarin.png` (логотип завода) + написанный вручную бриф. Остальное — создавать в процессе.

**Что НЕ смешивать**: стиль этого бренда радикально отличается от ФИЛЛС и BrewPrompt. Не переносить градиенты, grain или Inter в этот проект.

## Что делать на старте

1. Создать 4 проекта в Claude Design: `FILLS-creatives`, `LYTKARIN-BEER-creatives`, `BREWPROMPT-creatives`, `LYTKARIN-LEMONADY-creatives`.

2. Создать папку `ASSETS-PUBLIC/` локально. Положить в неё `logo_lytkarin.png`. Загружать в каждый проект, где нужен логотип завода.

3. Для ФИЛЛС: загрузить бриф → развёртки (6 PNG) → фото банок (`assets/fills_*.png`) → палитру SKU → состав+КБЖУ.

4. Для ЛыткаринЪ пиво: загрузить логотип → скриншот `vizitki.html` → бриф из `strategiya.md`.

5. Для BrewPrompt: написать стартовый бриф руками (шаблон выше) → собрать mood-board из Bakunin / Stamm / AF Brew → загрузить.

6. Для лимонадов (если запускаются): написать бриф → `logo_lytkarin.png` → загрузить.

7. В каждом проекте создать набор шаблонных форматов:

| Формат | Размер | Применение |
|--------|--------|------------|
| Instagram Stories | 1080×1920 px | Анонсы, акции |
| Instagram Feed | 1080×1080 px | Продуктовые посты |
| Карточка маркетплейса | 900×1200 px | Wildberries, Ozon |
| Баннер | 1280×720 px | Digital-реклама |
| Билборд | 6000×3000 px (1:2) | Офлайн, 6×3 м |
| A4 print | 2480×3508 px (300 dpi) | POS, листовки |

8. Для ФИЛЛС: создать цветовой скрипт — шаблон берёт токен SKU и меняет все цветовые зоны. На каждый из 6 SKU одним действием = 6 вариаций за сессию.
