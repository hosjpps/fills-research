# ФИЛЛС — профиль бренда

Лимонады в банках 0.45 л. Первый продукт под новым зонтиком.

---

## Линейка SKU

| Вкус | Роль | Цвет банки | Главный конкурент |
|---|---|---|---|
| Клубника + Базилик | Флагман | Коралл → мятный | Bakunin |
| Виноград + Крем-сода | Мост от классики | Фиолет → беж | Абрау Vinonade |
| Клюква + Апельсин + Розмарин | Adult appeal | Бордо → терракот | Gypsy Queen |
| Клубника + Арбуз | Volume driver | Коралл → ярко-розовый | Lapochka, Волчок |
| Огурец + Лимон + Лайм | Wellness / ЗОЖ | Бледно-зелёный → прозрачный | Holy Water |
| Гранат + Клубника + Грейпфрут + Чили | Wow-SKU | Глубокий красный → розовый | Lapochka |

---

## Позиционирование

Ценовая полка: **65–85 ₽**. Пустая ниша между массмаркетом (50–70 ₽) и крафтом (130–200 ₽).

Позиционирование: "вкусный лимонад без объяснений" — не ЗОЖ-декларация, не крафтовый снобизм, просто правильно сделанный продукт с интересным вкусом.

---

## Целевая аудитория

- Возраст: 20–35 лет
- Городские, инстаграм-активные
- Готовы платить немного больше, если упаковка красивая
- Не охотятся за функциональностью (пробиотики, витамины)

---

## Дизайн-DNA

- Форм-фактор: банка 0.45 л, матовое покрытие
- Финишинг: Spot UV логотип
- Стилистика: градиент + grain, минимализм, без иллюстраций
- Типографика: Inter + Space Grotesk
- Метод: каждый SKU — уникальный цветовой градиент, объединяет фирменная сетка

## Чего НЕ делать

- Не добавлять "Ъ" в логотип — занял Калиновъ, будет путаница
- Не запускать Cola-вкус — массовый сегмент, ФИЛЛС туда не идёт
- Не стекло — банка 0.45 принципиальна для экономики
- Не функциональные добавки (пробиотики и т.д.) на старте — сложнее сертификация, дороже
- Не ретро-дизайн — занят соседними брендами
